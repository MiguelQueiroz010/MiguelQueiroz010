**Tecnologias:** C#, .NET (Biblioteca ISO9660+UDF de escrita própria feita em 2021)

### Ferramentas de Engenharia Reversa
Conjunto de ferramentas e scripts próprios para análise de software e arquivos binários, incluindo depuração de baixo nível.
**Tecnologias:** C, C#, Python, Assembly/MIPS (análise manual e com ajuda de agente de IA)

### Ultimate Ninja BR
Projeto de localização e desenvolvimento de ferramentas para a série de jogos Naruto: Ultimate Ninja, incluindo extração de dados, manipulação de arquivos, localização de texto, aplicação de patches, análise de memória e engenharia reversa.
**Tecnologias:** C, C#, Python, Assembly/MIPS (uso geral de ferramentas)
